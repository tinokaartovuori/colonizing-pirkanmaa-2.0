\subsection{Detailed Description}
The \hyperlink{class_course_1_1_tile_base}{Tile\-Base} class is a base-\/class for different Tile-\/objects in the game. 

Buildings can be placed on the tile depending on the tile. Six units can be placed on any tile (conquering plus non-\/conquering)
