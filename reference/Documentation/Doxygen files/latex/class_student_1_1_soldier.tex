\subsection{Detailed Description}
The \hyperlink{class_student_1_1_soldier}{Soldier} class represents a soldier in the game. 

The soldier can conquer tiles owned by another player if the tile has more soldiers than the opponent. Adding the unit costs money and metal. A salary has to be payed when the round ends.
