\subsection{Detailed Description}
The \hyperlink{class_student_1_1_village}{Village} class represents a village in the game. 

It costs to build it and it consumes resources but it lets the player to have more Basic\-Workers and Experts.

Check \hyperlink{resourcemaps_8h_source}{Core/resourcemaps.\-h} V\-I\-L\-L\-A\-G\-E\-\_\-\-P\-R\-O\-D\-U\-C\-T\-I\-O\-N, V\-I\-L\-L\-A\-G\-E\-\_\-\-B\-U\-I\-L\-D\-\_\-\-C\-O\-S\-T and V\-I\-L\-L\-A\-G\-E\-\_\-\-U\-N\-I\-T\-\_\-\-V\-A\-L\-U\-E for the effects.
