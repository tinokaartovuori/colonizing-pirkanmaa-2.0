\subsection{Detailed Description}
The \hyperlink{class_course_1_1_farm}{Farm} class represents a farm building in the game. 

The player can grow crops on the farm which produces money. One worker is needed to operate the farm. The farm has a growth cycle which is updated visually. When growth\-Phase\-\_\- reaches 5 the crop is immediately harvested.
