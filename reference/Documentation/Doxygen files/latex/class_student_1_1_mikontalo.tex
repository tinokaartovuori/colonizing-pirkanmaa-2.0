\subsection{Detailed Description}
The \hyperlink{class_student_1_1_mikontalo}{Mikontalo} class represents a \hyperlink{class_student_1_1_mikontalo}{Mikontalo} in the game. 

It costs to build it and it consumes resources but it lets the player to have more Basic\-Workers and Experts.

Check \hyperlink{resourcemaps_8h_source}{Core/resourcemaps.\-h} M\-I\-K\-O\-N\-T\-A\-L\-O\-\_\-\-P\-R\-O\-D\-U\-C\-T\-I\-O\-N, M\-I\-K\-O\-N\-T\-A\-L\-O\-\_\-\-B\-U\-I\-L\-D\-\_\-\-C\-O\-S\-T and Mikontalo\-\_\-\-U\-N\-I\-T\-\_\-\-V\-A\-L\-U\-E for the effects.
