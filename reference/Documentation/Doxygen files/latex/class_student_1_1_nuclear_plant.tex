\subsection{Detailed Description}
The \hyperlink{class_student_1_1_nuclear_plant}{Nuclear\-Plant} class represents a nuclear power plant in the game. 

It costs to build it and it consumes resources but produces lots of gold. An expert and a basic worker is required to operate the plant. A second worker doubles the production

Check \hyperlink{resourcemaps_8h_source}{Core/resourcemaps.\-h} N\-U\-C\-L\-E\-A\-R\-P\-P\-\_\-\-P\-R\-O\-D\-U\-C\-T\-I\-O\-N and N\-U\-C\-L\-E\-A\-R\-P\-P\-\_\-\-B\-U\-I\-L\-D\-\_\-\-C\-O\-S\-T for the specific resources
