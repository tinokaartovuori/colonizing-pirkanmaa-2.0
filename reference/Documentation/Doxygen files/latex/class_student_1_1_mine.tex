\subsection{Detailed Description}
The \hyperlink{class_student_1_1_mine}{Mine} class represents a mine in the game. 

It costs to build it and it consumes resources but produces money, stone and metal. A basic worker is required to operate the mine. An expert improves the efficiency.

Check \hyperlink{resourcemaps_8h_source}{Core/resourcemaps.\-h} M\-I\-N\-E\-\_\-\-P\-R\-O\-D\-U\-C\-T\-I\-O\-N and M\-I\-N\-E\-\_\-\-B\-U\-I\-L\-D\-\_\-\-C\-O\-S\-T for the specific resources
