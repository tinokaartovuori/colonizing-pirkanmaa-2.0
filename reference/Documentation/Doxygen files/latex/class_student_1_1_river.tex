\subsection{Detailed Description}
The \hyperlink{class_student_1_1_river}{River} class represents \hyperlink{class_student_1_1_river}{River} in the gameworld. 

A bridge and a hydroelectric power plant can be built on the tile. If the river is a \char`\"{}corner piece\char`\"{}, nothing can be built on it.
