\subsection{Detailed Description}
The \hyperlink{class_student_1_1_abundant_forest}{Abundant\-Forest} class represents a Abundant Forest tile in the gameworld. 

\hyperlink{class_student_1_1_abundant_forest}{Abundant\-Forest} is the free way to get some money. Check \hyperlink{resourcemaps_8h_source}{Core/resourcemaps.\-h} A\-B\-U\-N\-D\-A\-N\-T\-\_\-\-F\-O\-R\-E\-S\-T\-\_\-\-P\-R\-O\-D\-U\-C\-T\-I\-O\-N for specific Resource\-Map values. Abundant Forest can be harvested every round for little money.
