\subsection{Detailed Description}
The \hyperlink{class_course_1_1_basic_worker}{Basic\-Worker} class represents a \char`\"{}\-Basic\-Worker\char`\"{} in the game. 

The unit can work in various buildings and is needed to get resources from the buildings. The worker also can cut down forest. Adding the unit costs money and the worker also has a salary that is payed when the round ends. The unit can conquer new areas too if the tile has no owner
